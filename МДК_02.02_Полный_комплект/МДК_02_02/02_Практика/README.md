# Практические задания МДК 02.02 на Python

25 билетов. Для каждого выполнено практическое задание № 3 из исходного документа.

## Требования

- Python 3.10 или новее.
- Сторонние Python-пакеты не нужны: используется только стандартная библиотека.
- Для билетов 08–11 нужен Git в PATH. Можно указать путь в переменной GIT_EXECUTABLE.
- Интернет не требуется.

## Быстрый запуск

Распакуйте архив целиком. Откройте терминал в распакованной папке.

```text
python run_all.py
```

Команда запускает автоматические тесты и демонстрации всех 25 билетов, проверяет синтаксис и формирует CHECK_REPORT.md и verification_logs/. При ошибке возвращает ненулевой код завершения. Проверки Git работают в отдельных временных каталогах и не меняют ваши репозитории и глобальные настройки.

## Один билет

```text
cd ticket_01
python main.py
python tests.py
```

main.py по умолчанию запускает готовые примеры без ожидания ввода. Числа и строки можно изменить в примерах main.py или передать непосредственно функциям модуля. В билетах 04, 15, 16 и 18 доступен ручной ввод: python main.py --interactive. В каждом каталоге есть README.md с точным условием, пояснениями и именами файлов.
