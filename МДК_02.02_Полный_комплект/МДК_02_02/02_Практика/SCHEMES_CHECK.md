## Как открыть

Распакуйте архив. В draw.io: Файл → Открыть из → Устройство → SCHEME.drawio из папки билета. Общий файл Схемы_МДК_02_02.drawio содержит все 11 схем отдельными страницами. PNG рядом с каждым файлом — предпросмотр.

Схемы отражают реальные имена модулей, функций, типы и направление передачи данных. Оформление: Times New Roman, белый фон, чёрные рамки и стрелки, как в комплекте МДК 02.01.

## Пределы проверки

Проверены локально структура XML, идентификаторы и связи, геометрия, соответствие интерфейсов исходному коду и PNG. Предпросмотры построены по той же геометрии. Открытие в самом редакторе draw.io в рамках этого обновления не проверялось.

Повторить проверки схем: python check_schemes.py. Программы: python run_all.py.
