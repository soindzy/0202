# Билет 1 — Сложение двух чисел

## Условие

Разработайте два программных модуля: первый выполняет сложение двух чисел, второй вызывает первый и выводит результат. Опишите способ их взаимодействия.

## Запуск

```text
python main.py
python tests.py
```

Запускайте команды из каталога этого билета. main.py выполняет демонстрационные примеры; tests.py проверяет результаты независимо.

## Решение

Основной модуль импортирует add из addition.py, передаёт два аргумента и получает возвращаемую сумму. Функция вычисления не печатает результат: вывод выполняет main.py.

## Файлы

- addition.py
- main.py
- tests.py — автоматические проверки на unittest.

## Схема взаимодействия

SCHEME.drawio — редактируемая схема модулей для draw.io. SCHEME.png — предпросмотр. Файл открывается через Файл → Открыть из → Устройство. Названия модулей и функций соответствуют программам этого билета.
