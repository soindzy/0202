# Билет 2 — Площадь прямоугольника

## Условие

Разделите приложение для вычисления площади прямоугольника на вычислительный и основной модули. Продемонстрируйте их интеграцию.

## Запуск

```text
python main.py
python tests.py
```

Запускайте команды из каталога этого билета. main.py выполняет демонстрационные примеры; tests.py проверяет результаты независимо.

## Решение

geometry.py выполняет расчёт, main.py передаёт размеры и выводит результат или сообщение об ошибке. Нулевая сторона допускается как вырожденный прямоугольник.

## Файлы

- geometry.py
- main.py
- tests.py — автоматические проверки на unittest.

## Схема взаимодействия

SCHEME.drawio — редактируемая схема модулей для draw.io. SCHEME.png — предпросмотр. Файл открывается через Файл → Открыть из → Устройство. Названия модулей и функций соответствуют программам этого билета.
