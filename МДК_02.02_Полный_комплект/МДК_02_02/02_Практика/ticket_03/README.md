# Билет 3 — Преобразование температуры

## Условие

Разработайте отдельный модуль преобразования температуры из градусов Цельсия в градусы Фаренгейта. Подключите его к основной программе и проверьте результат.

## Запуск

```text
python main.py
python tests.py
```

Запускайте команды из каталога этого билета. main.py выполняет демонстрационные примеры; tests.py проверяет результаты независимо.

## Решение

Используется формула F = C × 9 / 5 + 32. Импорт связывает основной модуль с вычислительным.

## Файлы

- temperature.py
- main.py
- tests.py — автоматические проверки на unittest.

## Схема взаимодействия

SCHEME.drawio — редактируемая схема модулей для draw.io. SCHEME.png — предпросмотр. Файл открывается через Файл → Открыть из → Устройство. Названия модулей и функций соответствуют программам этого билета.
