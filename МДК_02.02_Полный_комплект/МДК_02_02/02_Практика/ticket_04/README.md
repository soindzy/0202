# Билет 4 — Модульный калькулятор

## Условие

Составьте схему модулей приложения «Калькулятор»: ввод данных, вычисления, вывод результата. Укажите связи и интерфейсы.

## Запуск

```text
python main.py
python tests.py
```

Запускайте команды из каталога этого билета. main.py выполняет демонстрационные примеры; tests.py проверяет результаты независимо.

## Решение

В SCHEME.md приведены связи и интерфейсы требуемой схемы. Реализация дополнительно демонстрирует её работу. Для ручного ввода: python main.py --interactive.

## Файлы

- input_data.py
- calculator.py
- output_data.py
- main.py
- SCHEME.md
- tests.py — автоматические проверки на unittest.

## Схема взаимодействия

SCHEME.drawio — редактируемая схема модулей для draw.io. SCHEME.png — предпросмотр. Файл открывается через Файл → Открыть из → Устройство. Названия модулей и функций соответствуют программам этого билета.
