# Схема модулей калькулятора

Пользователь -> input_data.parse_request(text) -> (a, operation, b)
-> calculator.calculate(a, operation, b) -> число
-> output_data.format_result(value) -> строка -> экран.

main.py управляет вызовами и обрабатывает ошибки.
Ввод принимает строку; вычислительный модуль принимает два числа и знак операции;
вывод принимает числовой результат. Модули не обращаются к внутренним данным друг друга.
