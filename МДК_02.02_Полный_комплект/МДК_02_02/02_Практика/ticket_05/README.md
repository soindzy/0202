# Билет 5 — Максимум последовательности

## Условие

Разработайте модуль поиска максимального элемента последовательности и основную программу, передающую данные этому модулю. Проверьте взаимодействие.

## Запуск

```text
python main.py
python tests.py
```

Запускайте команды из каталога этого билета. main.py выполняет демонстрационные примеры; tests.py проверяет результаты независимо.

## Решение

Вычисление выделено в отдельный модуль. main.py передаёт исходные данные и выводит результат; tests.py проверяет обычные и граничные случаи.

## Файлы

- maximum.py
- main.py
- tests.py — автоматические проверки на unittest.

## Схема взаимодействия

SCHEME.drawio — редактируемая схема модулей для draw.io. SCHEME.png — предпросмотр. Файл открывается через Файл → Открыть из → Устройство. Названия модулей и функций соответствуют программам этого билета.
