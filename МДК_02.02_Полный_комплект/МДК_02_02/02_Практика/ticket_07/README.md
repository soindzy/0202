# Билет 7 — Получение и суммирование цен

## Условие

Спроектируйте взаимодействие трёх модулей: получение списка цен, вычисление суммы и вывод результата. Реализуйте передачу данных между ними.

## Запуск

```text
python main.py
python tests.py
```

Запускайте команды из каталога этого билета. main.py выполняет демонстрационные примеры; tests.py проверяет результаты независимо.

## Решение

Три рабочих модуля: источник цен -> вычисление суммы -> оформление вывода. main.py связывает их. Decimal из стандартной библиотеки исключает двоичную погрешность при работе с деньгами.

## Файлы

- price_source.py
- price_total.py
- price_output.py
- main.py
- tests.py — автоматические проверки на unittest.
