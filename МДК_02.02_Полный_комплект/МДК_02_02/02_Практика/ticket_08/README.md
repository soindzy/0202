# Билет 8 — Исключение временных файлов

## Условие

Для проекта с основным модулем, вспомогательным модулем, тестами и текстовой документацией составьте правила исключения временных файлов из репозитория. Объясните назначение правил.

## Запуск

```text
python main.py
python tests.py
```

Запускайте команды из каталога этого билета. main.py выполняет демонстрационные примеры; tests.py проверяет результаты независимо.

## Решение

Правила приведены в настоящем .gitignore с поясняющими комментариями. Исходники, тесты и документация не исключаются. Правила проверяются настоящей командой git check-ignore в отдельном временном репозитории. Для запуска тестов нужен Git. Уже отслеживаемые файлы .gitignore не удаляет из истории.

## Файлы

- .gitignore
- helper.py
- main.py
- git_support.py
- docs/PROJECT.md
- tests.py — автоматические проверки на unittest.
