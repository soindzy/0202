# Билет 9 — Создание репозитория и коммит

## Условие

Составьте последовательность действий и команд системы контроля версий для создания репозитория, добавления исходного файла и фиксации изменений. Поясните каждый этап.

## Запуск

```text
python main.py
python tests.py
```

Запускайте команды из каталога этого билета. main.py выполняет демонстрационные примеры; tests.py проверяет результаты независимо.

## Решение

Команды в новом каталоге: git init -b main — создать репозиторий; создать hello.py; git add hello.py — поместить файл в индекс; git commit -m "Add hello program" — сохранить снимок; git status — проверить состояние; git log --oneline — просмотреть историю. Перед первым коммитом нужны user.name и user.email. Скрипт задаёт учебные значения только для своих вызовов, не меняя глобальных настроек.
