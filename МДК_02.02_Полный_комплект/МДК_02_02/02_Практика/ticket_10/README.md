# Билет 10 — Создание ветки и слияние

## Условие

Составьте последовательность действий и команд системы контроля версий для создания отдельной ветки разработки и объединения её с основной веткой.

## Запуск

```text
python main.py
python tests.py
```

Запускайте команды из каталога этого билета. main.py выполняет демонстрационные примеры; tests.py проверяет результаты независимо.

## Решение

После исходного коммита: git checkout -b feature — создать ветку и перейти в неё; изменить файлы; git add и git commit — сохранить работу; git checkout main — вернуться в основную ветку; git merge --no-ff feature -m "Merge feature" — объединить изменения отдельным коммитом слияния. Скрипт реально выполняет все команды в новом временном репозитории.
