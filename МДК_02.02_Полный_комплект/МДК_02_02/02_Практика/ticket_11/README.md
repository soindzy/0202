# Билет 11 — Воспроизведение и разрешение конфликта

## Условие

Опишите порядок разрешения конфликта слияния, возникшего из-за изменения одной настройки в общем конфигурационном файле двумя разработчиками. Приведите согласованный результат.

## Запуск

```text
python main.py
python tests.py
```

Запускайте команды из каталога этого билета. main.py выполняет демонстрационные примеры; tests.py проверяет результаты независимо.

## Решение

Обе ветки меняют одну строку config.ini. git merge feature создаёт конфликт. Порядок решения: git status; изучить обе правки; согласовать значение; заменить блок с маркерами окончательной строкой timeout = 30; git add config.ini; git commit. Значение 30 — выбранное учебное решение, в настоящем проекте его согласуют по требованиям. Скрипт воспроизводит конфликт и проверяет, что после исправления нет неслитых файлов.
