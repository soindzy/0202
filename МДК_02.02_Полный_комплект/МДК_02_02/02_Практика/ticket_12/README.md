# Билет 12 — Безопасное деление

## Условие

Разработайте алгоритм деления двух чисел с обработкой попытки деления на ноль. Покажите результаты для корректных и некорректных входных данных.

## Запуск

```text
python main.py
python tests.py
```

Запускайте команды из каталога этого билета. main.py выполняет демонстрационные примеры; tests.py проверяет результаты независимо.

## Решение

Алгоритм: проверить типы -> проверить делитель -> вычислить частное. main.py перехватывает исключения и демонстрирует корректные и некорректные данные.

## Файлы

- division.py
- main.py
- tests.py — автоматические проверки на unittest.
