# Билет 13 — Квадрат числа и тестовые случаи

## Условие

Для функции вычисления квадрата числа составьте не менее четырёх тестовых случаев с входными данными и ожидаемыми результатами.

## Запуск

```text
python main.py
python tests.py
```

Запускайте команды из каталога этого билета. main.py выполняет демонстрационные примеры; tests.py проверяет результаты независимо.

## Решение

Четыре обязательных случая: 2 -> 4; 0 -> 0; -3 -> 9; 1.5 -> 2.25. Ожидания заданы заранее независимо от вычисляемого результата.

## Файлы

- square.py
- main.py
- tests.py — автоматические проверки на unittest.
