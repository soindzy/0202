# Билет 14 — Исправление среднего арифметического

## Условие

В алгоритме вычисления среднего арифметического двух чисел допущена ошибка: сначала складывается первое число с половиной второго. Исправьте алгоритм и предложите три теста.

## Запуск

```text
python main.py
python tests.py
```

Запускайте команды из каталога этого билета. main.py выполняет демонстрационные примеры; tests.py проверяет результаты независимо.

## Решение

Ошибочная формула a + b / 2 заменена на (a + b) / 2. Проверки: (2, 4) -> 3; (-4, 4) -> 0; (0, 0) -> 0. Первые два случая выявляют исходный дефект.
