# Билет 15 — Проверка возраста

## Условие

Разработайте проверку возраста: допустимы целые значения от 0 до 120 включительно. Предусмотрите обработку неверного типа данных и выхода за диапазон.

## Запуск

```text
python main.py
python tests.py
```

Запускайте команды из каталога этого билета. main.py выполняет демонстрационные примеры; tests.py проверяет результаты независимо.

## Решение

Функция принимает только int в диапазоне 0–120; строки, float и bool отклоняет. В интерактивном режиме строка сначала преобразуется в int, ошибка преобразования перехватывается. Запуск: python main.py --interactive.

## Файлы

- age_validation.py
- main.py
- tests.py — автоматические проверки на unittest.
