# Билет 16 — Проверка непустой строки

## Условие

Разработайте модуль проверки непустой строки и основную программу, использующую результат проверки. Продемонстрируйте обработку пустого ввода.

## Запуск

```text
python main.py
python tests.py
```

Запускайте команды из каталога этого билета. main.py выполняет демонстрационные примеры; tests.py проверяет результаты независимо.

## Решение

Принято правило: строка из одних пробельных символов считается пустым вводом. main.py использует логический результат модуля. Ручной ввод: python main.py --interactive.

## Файлы

- text_validation.py
- main.py
- tests.py — автоматические проверки на unittest.

## Схема взаимодействия

SCHEME.drawio — редактируемая схема модулей для draw.io. SCHEME.png — предпросмотр. Файл открывается через Файл → Открыть из → Устройство. Названия модулей и функций соответствуют программам этого билета.
