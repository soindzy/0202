# Билет 17 — Сортировка и пять сценариев

## Условие

Для модуля сортировки последовательности составьте пять тестовых сценариев, включая пустую последовательность и повторяющиеся значения. Укажите ожидаемые результаты.

## Запуск

```text
python main.py
python tests.py
```

Запускайте команды из каталога этого билета. main.py выполняет демонстрационные примеры; tests.py проверяет результаты независимо.

## Решение

Пять сценариев и ожидаемые результаты приведены в main.py и зафиксированы независимыми проверками в tests.py: пустой список; несортированный; повторы; отрицательные числа; уже отсортированный список.

## Файлы

- sorting.py
- main.py
- tests.py — автоматические проверки на unittest.
