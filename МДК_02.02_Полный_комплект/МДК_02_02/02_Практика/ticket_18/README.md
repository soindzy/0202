# Билет 18 — Преобразование текста в целое число

## Условие

Разработайте алгоритм преобразования текстового ввода в целое число с обработкой ошибки преобразования. Проверьте его на значениях «15» и «abc».

## Запуск

```text
python main.py
python tests.py
```

Запускайте команды из каталога этого билета. main.py выполняет демонстрационные примеры; tests.py проверяет результаты независимо.

## Решение

Алгоритм использует int(text) внутри try/except. Для «15» результат 15; для «abc» — понятное сообщение без аварийного завершения. Ручной ввод: python main.py --interactive.

## Файлы

- conversion.py
- main.py
- tests.py — автоматические проверки на unittest.
