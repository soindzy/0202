# Билет 19 — Безопасный доступ по индексу

## Условие

Разработайте безопасное получение элемента последовательности по индексу с обработкой выхода за границы. Покажите корректный и ошибочный случаи.

## Запуск

```text
python main.py
python tests.py
```

Запускайте команды из каталога этого билета. main.py выполняет демонстрационные примеры; tests.py проверяет результаты независимо.

## Решение

В этом решении отрицательные индексы запрещены явным контрактом, хотя обычный Python допускает их для обращения с конца. Ошибка обрабатывается в основном модуле, а не подменяется произвольным значением.

## Файлы

- safe_access.py
- main.py
- tests.py — автоматические проверки на unittest.
