# Билет 20 — Чётность и четыре автотеста

## Условие

Для функции определения чётности числа разработайте четыре автоматизированные проверки: чётное число, нечётное, ноль и отрицательное число.

## Запуск

```text
python main.py
python tests.py
```

Запускайте команды из каталога этого билета. main.py выполняет демонстрационные примеры; tests.py проверяет результаты независимо.

## Решение

Ровно четыре требуемые автоматизированные проверки: чётное число 8, нечётное 7, ноль и отрицательное чётное -4.

## Файлы

- parity.py
- main.py
- tests.py — автоматические проверки на unittest.
