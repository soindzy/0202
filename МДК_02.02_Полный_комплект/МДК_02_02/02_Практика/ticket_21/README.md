# Билет 21 — Исправление суммирования

## Условие

Найдите и исправьте логическую ошибку в алгоритме суммирования последовательности, где накопленная сумма на каждом шаге заменяется текущим элементом. Составьте проверочный тест.

## Запуск

```text
python main.py
python tests.py
```

Запускайте команды из каталога этого билета. main.py выполняет демонстрационные примеры; tests.py проверяет результаты независимо.

## Решение

Причина: присваивание total = value теряет предыдущую сумму. Замена на total += value сохраняет накопление. Проверочный тест [1, 2, 3] должен вернуть 6; ошибочный алгоритм вернул бы 3.

## Файлы

- summation.py
- main.py
- tests.py — автоматические проверки на unittest.
