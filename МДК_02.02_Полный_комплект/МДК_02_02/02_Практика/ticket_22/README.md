# Билет 22 — Скидка и оформление суммы

## Условие

Разработайте два взаимодействующих модуля: расчёт скидки 10% от цены и форматирование итоговой суммы. Проверьте совместную работу на двух примерах.

## Запуск

```text
python main.py
python tests.py
```

Запускайте команды из каталога этого билета. main.py выполняет демонстрационные примеры; tests.py проверяет результаты независимо.

## Решение

discount.py возвращает итоговую цену после скидки, formatting.py преобразует её в сообщение. Для денег используется Decimal и округление до копеек ROUND_HALF_UP. Два обязательных примера: 1000.00 -> 900.00; 250.50 -> 225.45.

## Файлы

- discount.py
- formatting.py
- main.py
- tests.py — автоматические проверки на unittest.
