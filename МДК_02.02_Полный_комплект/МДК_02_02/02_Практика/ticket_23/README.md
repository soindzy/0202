# Билет 23 — Журнал тестирования деления

## Условие

Составьте журнал тестирования операции деления двух чисел: не менее четырёх тестов с входными данными, ожидаемыми и фактическими результатами.

## Запуск

```text
python main.py
python tests.py
```

Запускайте команды из каталога этого билета. main.py выполняет демонстрационные примеры; tests.py проверяет результаты независимо.

## Решение

Пять проверок: обычное деление, нулевое делимое, отрицательное число, деление на ноль и неверный тип. JOURNAL.md формируется запуском настоящей функции; фактические результаты не подставляются из ожидаемых. Для повторного просмотра выполните python main.py.

## Файлы

- division.py
- journal.py
- main.py
- tests.py — автоматические проверки на unittest.
