# Билет 24 — Длина строки

## Условие

Разработайте модуль определения длины строки и основную программу для его вызова. Предусмотрите тесты для пустой строки, обычного текста и строки с пробелами.

## Запуск

```text
python main.py
python tests.py
```

Запускайте команды из каталога этого билета. main.py выполняет демонстрационные примеры; tests.py проверяет результаты независимо.

## Решение

Пробелы считаются символами. Используется len(str): это число кодовых точек Unicode, а не число байтов и не всегда количество визуальных графем.

## Файлы

- text_length.py
- main.py
- tests.py — автоматические проверки на unittest.
