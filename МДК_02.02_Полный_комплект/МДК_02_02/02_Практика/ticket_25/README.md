# Билет 25 — Передача данных пользователя

## Условие

Разработайте преобразование данных пользователя (имя и возраст) в текстовое сообщение. Покажите передачу данных между двумя программными модулями.

## Запуск

```text
python main.py
python tests.py
```

Запускайте команды из каталога этого билета. main.py выполняет демонстрационные примеры; tests.py проверяет результаты независимо.

## Решение

user_data.py создаёт проверенный объект User (имя и возраст), user_message.py получает этот объект и формирует сообщение. main.py демонстрирует передачу данных между двумя модулями.

## Файлы

- user_data.py
- user_message.py
- main.py
- tests.py — автоматические проверки на unittest.

## Схема взаимодействия

SCHEME.drawio — редактируемая схема модулей для draw.io. SCHEME.png — предпросмотр. Файл открывается через Файл → Открыть из → Устройство. Названия модулей и функций соответствуют программам этого билета.
