# Проверка интерактивного ввода

Билет 04; ввод '8 * 3\n'; PASS
Пример (10 + 2): 8 * 3 -> Результат: 24

Билет 04; ввод '1 / 0\n'; PASS
Пример (10 + 2): 1 / 0 -> Ошибка: Деление на ноль запрещено

Билет 15; ввод '120\n'; PASS
Возраст (целое число 0–120): Возраст принят: 120

Билет 15; ввод 'abc\n'; PASS
Возраст (целое число 0–120): Ошибка: invalid literal for int() with base 10: 'abc'

Билет 15; ввод '121\n'; PASS
Возраст (целое число 0–120): Ошибка: Возраст должен быть от 0 до 120 включительно

Билет 16; ввод 'Привет\n'; PASS
Введите текст: 'Привет' -> Принято: Привет

Билет 16; ввод '\n'; PASS
Введите текст: '' -> Ошибка: ввод не должен быть пустым

Билет 18; ввод '15\n'; PASS
Введите целое число: '15' -> 15

Билет 18; ввод 'abc\n'; PASS
Введите целое число: 'abc' -> Ошибка: Введите целое число, например 15
