ПОЛНЫЙ КОМПЛЕКТ МДК 02.02

00_Билеты — исходный документ с 25 билетами.
01_Теория — Word-документ с ответами на 50 теоретических вопросов.
02_Практика — Программы Python всех 25 билетов, тесты и результаты проверок; 11 схем draw.io и общий альбом.
03_Отчёты — 25 отдельных Word-отчётов по практическим заданиям.

Отчёты оформлены по основным правилам ГОСТ 7.32–2017 и не содержат личных данных и полей для заполнения.

Откройте README.md в 02_Практика для инструкции к практическим работам. Вложенные ZIP распаковывать не требуется: все материалы уже разложены по папкам.

Программы: требуется Python 3.10 или новее; сторонние Python-пакеты не нужны. Для билетов 08–11 нужен Git. Из папки 02_Практика выполните python run_all.py; схемы проверяются командой python check_schemes.py. Открытие схем в самом draw.io не подтверждено.
